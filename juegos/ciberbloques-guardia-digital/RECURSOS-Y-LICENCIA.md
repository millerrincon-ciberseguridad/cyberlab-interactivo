# Recursos y licencia del paquete

## Código e interfaz

El código HTML, CSS y JavaScript, el logo predeterminado, la identidad visual de las piezas y los sonidos generados mediante Web Audio son recursos originales creados específicamente para `CiberBloques: Guardia Digital`.

## Imagen de fondo

`assets/fondo-anonymous.webp` es una imagen nueva, generada para este paquete y procesada con recorte, desenfoque y ajuste de luminosidad. No procede de una película, videojuego, fotografía comercial ni banco de imágenes.

La imagen representa de manera genérica una máscara asociada culturalmente con Anonymous. No contiene logotipos, texto, marcas de terceros ni una reproducción de una fotografía existente.

## Exclusiones

Este paquete no contiene ni reclama relación con el videojuego comercial citado como referencia de género. No incorpora su nombre en la interfaz, código, logotipos, tipografías, música, efectos de sonido, capturas, diseños de tablero ni otros activos protegidos.

## Uso

El paquete se entrega para su incorporación al sitio Ciberaula. La organización administradora puede personalizar logo, texto, rutas y parámetros de juego mediante `config.js`.
